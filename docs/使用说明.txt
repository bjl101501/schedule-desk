日程台 · 个人日程工作台（桌面版 v2）
=====================================

启动
----
双击 ScheduleDesk.exe，单文件即可运行，无需安装。

（GitHub 发布版用 MSVC 构建，WebView2 加载器已静态链接进 exe。
若你自行用 GNU 工具链构建，则需要把 WebView2Loader.dll 放在同目录。）

首次打开
--------
会先让你选数据存放位置：
· 默认目录：%APPDATA%\ScheduleDesk\data
· 想多台电脑自动一致，就选 OneDrive / 坚果云等同步盘里的目录

选完点「开始使用」，程序会自动重启进入主界面。

数据在哪
--------
数据目录下有这些文件：
  schedule.json          主数据
  schedule.backup.json   上一版备份
  notified.json          已发送的提醒记录
  snapshots\             每日快照，保留 7 天

设置 → 数据目录 里可以随时更换，旧数据会自动搬过去并重启。

同步
----
两种方式，任选其一，不要同时用：

1) 网盘同步盘
   把数据目录设在 OneDrive/坚果云里，由网盘客户端负责搬运。
   两台电脑不要同时开着改数据，否则网盘会生成「副本」文件。

2) WebDAV
   设置 → WebDAV 同步，填地址、用户名、密码，点「保存并同步」。
   程序自己拉取远端、按每条记录的修改时间合并、再上传。
   删除也会同步到其他设备。适合坚果云、Nextcloud、群晖。

右上角状态含义：
  本地模式  只在本机保存，没配 WebDAV
  同步中    正在跟远端交换数据
  已同步    上次同步成功
  同步失败  点开看提示，多为地址或密码问题

日程的时间与「逾期」
--------------------
提醒和逾期都以「开始时间」为基准，不再只看日期：

· 填了开始时间 + 预计时长
  开始前：未开始；提醒到点后显示「即将开始」
  开始后：显示「正在进行 · 剩余 xx」，超过「开始 + 时长」还没完成才是「已逾期」

· 填了开始时间、没填预计时长
  到点未完成就算「已逾期」；设了提前提醒的，提醒到点后先显示「即将逾期」

· 开始时间留空＝全天日程
  当天一直显示「全天 · 进行中」，过了这一天才是「已逾期」
  预计时长留空也按全天处理；填了时长也不改变全天任务的逾期判定

· 跨天任务（勾了「持续」）
  到结束日之后才算逾期；子项各自按排期判断，未完成会标「子项逾期」

提醒与托盘
----------
· 到点用 Windows 原生通知弹出，不需要开着窗口
· 通知会一直留在屏幕上，直到你点关闭（不再几秒后自己消失）
· 通知文案取自日程本身：标题、开始时间、预计时长都会带上
· 全天日程的提醒基准是当天 09:00（可在「基准时间」里改）
· 关闭窗口只是隐藏到托盘，计时和提醒继续跑；再次双击 exe 会把已有窗口唤到前台
· 右键托盘图标：打开主界面 / 立即同步 / 退出
· 要完全退出，用托盘菜单的「退出」

新建日程的小技巧
----------------
· 日期、时间都是自绘面板：点开选，点「清除」变回全天
· 标签支持一次加多个：用空格、回车或逗号分隔；也支持整段粘贴
· 「用已有日程填充」可以把相似日程的清单、标签、时长、子项、提醒一次带过来，
  日期和开始时间保持当前填的值
· 每个带「?」的字段都能悬停查看说明，不会挡住输入框

更新
----
设置 → 软件更新 → 检查更新。
有新版本会显示「立即更新」，点一下自动下载、替换、重启。

导出
----
「备份 → 导出 JSON / CSV」写入系统「下载」文件夹，完成后提示完整路径。

运行环境
--------
Windows 10 1809 及以上 / Windows 11，需要 WebView2 运行时
（Windows 11 与装了 Edge 的系统自带）。

首次运行提示
------------
本程序未做代码签名，从网络下载后首次运行，Windows SmartScreen 可能拦截。

推荐做法（一次设置，之后不再提示）：
  解压前右键 zip → 属性 → 勾选「解除锁定」→ 确定

已经解压过的，在程序目录执行：
  Get-ChildItem -Recurse | Unblock-File

也可以直接在提示里点「更多信息 → 仍要运行」。

这个提示是 Windows 对「来自网络、且没有下载记录」文件的默认拦截，
与程序本身无关；用的人多了会自行放行。

卸载
----
删除程序文件夹。若要彻底清干净，再删除：
  %APPDATA%\ScheduleDesk
以及 HKCU\Software\Classes\AppUserModelId\com.scheduledesk.app
